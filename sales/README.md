## When to Use Each Battlecard

### Use Inmar OneRecall Battlecard When:
- Prospect mentions OneRecall or "current vendor"
- Competing for enterprise health system deals
- Prospect values market share/credibility arguments
- Hear complaints about legacy systems or long implementations

### Use ECRI Battlecard When:
- Prospect mentions ECRI by name
- Price sensitivity in enterprise deals
- Prospect is evaluating "premium" options
- Hear about bundling pressure or high costs

### Use PAR Excellence Battlecard When:
- Competing for Standard tier deals (1-5 locations)
- Prospect mentions NotiSphere or PAR
- Price is the primary decision factor
- Need to differentiate on compliance/audit readiness
