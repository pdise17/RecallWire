## December 2025

### Pricing Simplification (December 31)
**Decision:** Consolidated from 4-tier to 2-tier pricing model

| Before | After |
|--------|-------|
| Starter: $1,499/yr | — |
| Professional: $3,999/yr | — |
| Business: $7,999/yr | — |
| Enterprise: $40,000+ | — |
| | **Standard: $4,999/yr** (1-5 locations) |
| | **Enterprise: $25,000+** (6+ locations) |

**Rationale:**
- Simplified buyer journey
- Clearer upgrade path
- Competitive positioning vs. PAR Excellence (Standard) and OneRecall/ECRI (Enterprise)

- `deliverables/10-pricing-one-pager.md` — Updated as source of truth
- `deliverables/05-pricing-addendum.md` — Consolidated into 06, deleted
- `deliverables/07-enterprise-pricing-margins.md` — Consolidated into 06, deleted
