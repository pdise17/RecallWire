# RecallWire Current State Analysis

## Executive Summary

RecallWire is a medical device recall management platform designed to automate recall detection, matching, and resolution workflows for healthcare organizations. The platform is built with enterprise-grade capabilities but faces a market positioning challenge: the product quality and feature depth supports enterprise pricing ($40k+/year), while the target market includes non-enterprise customers who expect pricing around $2,000/year per location.

---

## Product Capabilities

### Core Platform Features

| Feature | Description | Enterprise Value | SMB Value |
|---------|-------------|------------------|-----------|
| **Real-time Alerts Engine** | Aggregates FDA and non-FDA recall notices with prioritization and de-duplication | High | High |
| **Targeted Matching** | Matches recalls to POs, item masters, and inventory with confidence scoring | High | Medium |
| **Smart Routing & Escalations** | Auto-notifies by facility/department with SLA tracking | High | Low-Medium |
| **Guided Resolution** | Workflow for holds, removals, quarantines, returns with photo/note capture | High | High |
| **Reporting & Dashboards** | Org-wide and site-level views with export capabilities | High | Medium |
| **Audit-Ready Records** | Complete digital trail with role-based sign-offs | High | High |
| **RecallWire Assistant** | AI-powered guidance on recall codes and regulatory steps | Medium | Medium |

### Current Pricing Tier Structure

RecallWire currently offers three tiers (no public pricing disclosed):

#### Essential Tier
- **Target**: Single facilities
- **Features**:
  - CSV imports for data ingestion
  - Core dashboard functionality
  - Email notifications
  - Help center access

#### Professional Tier
- **Target**: Multi-site organizations
- **Features**:
  - Multi-facility hierarchy management
  - SLA escalations
  - Advanced dashboards
  - Department mapping
  - SSO readiness
  - API access (read-only)

#### Enterprise Tier
- **Target**: Large health systems
- **Features**:
  - Custom workflows
  - Sandbox environments
  - API write access
  - Data retention controls
  - Premium support
  - Security reviews

## Feature Analysis: Enterprise vs. Universal

### Universal Features (High value across all segments)
These features deliver value regardless of organization size:

1. **Real-time recall alerts** - Core value prop for any healthcare facility
2. **Audit trail / compliance documentation** - Regulatory requirement for all
3. **Guided resolution workflows** - Operational efficiency for any size
4. **Basic reporting** - Essential visibility

### Enterprise-Specific Features (Limited SMB value)
These features primarily serve larger, more complex organizations:

1. **Multi-facility hierarchy** - Only relevant for multi-site orgs
2. **Advanced SLA management** - Complex escalation paths
3. **SSO integration** - IT security requirement for large orgs
4. **API write access** - Integration with enterprise systems
5. **Custom workflows** - Process complexity at scale
6. **Sandbox environments** - Enterprise IT requirements
7. **Security reviews** - Procurement requirements

### Features with Scalable Value
These features can be tiered based on volume/complexity:

1. **PO/Inventory matching** - Value scales with volume
2. **Department routing** - Scales with org complexity
3. **Dashboard customization** - More valuable at scale
4. **Data retention controls** - Enterprise compliance requirement

## Current Pricing Challenge

### The Core Problem

| Dimension | Enterprise Reality | SMB Target |
|-----------|-------------------|------------|
| **Typical pricing** | $40,000+/year | ~$2,000/year per location |
| **Customer profile** | Large health systems, 100+ locations | Single facility clinics, ASCs |
| **Buying process** | Procurement, security review, contracts | Credit card, quick decisions |
| **Feature needs** | Full platform | Core compliance + workflows |
| **Support expectations** | Dedicated CSM, SLAs | Self-service, help center |

### Unit Economics Consideration

At $2,000/year per location:
- **Revenue per customer**: $167/month
- **Required margin structure**: Minimal touch, self-service onboarding
- **Support model**: Community/help center, minimal live support
- **Sales model**: Product-led, low-touch

At $40,000+/year per enterprise:
- **Revenue per customer**: $3,333+/month
- **Viable margin structure**: High-touch sales, dedicated support
- **Support model**: Named CSM, implementation services
- **Sales model**: Consultative, demo-driven

### The Gap

The 20x price differential between enterprise and SMB targets requires:
1. **Feature segmentation** - Clear tier boundaries
2. **Cost structure adjustment** - Self-service for lower tiers
3. **Sales motion change** - PLG for SMB, sales-led for enterprise
4. **Support tiering** - Appropriate for price point

---

## Recommendations Preview

Based on this analysis, the pricing strategy should address:

1. **Create a true self-service tier** at $99-199/month targeting single facilities
2. **Establish clear feature gates** that justify tier upgrades
3. **Design scalable pricing** (per-location or per-user) for mid-market
4. **Preserve enterprise pricing** with premium features and support
5. **Consider volume discounts** for multi-location SMB buyers
