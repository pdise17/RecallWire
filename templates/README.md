# Document Templates

Starter templates for adding new documents to the RecallWire repository.

## How to Use

1. Copy the relevant template to the target folder
2. Rename with appropriate numbering (e.g., `07-new-document.md`)
3. Fill in the sections
4. Update the folder's README.md to include the new document
5. Add entry to `/CHANGELOG.md`

## Available Templates

| Template | Use For | Target Folder |
|----------|---------|---------------|
| `strategy-document.md` | Pricing, go-to-market, analysis | `/deliverables/` |
| `market-research.md` | Industry data, competitive intel | `/medical_devices/` |
| `workflow-document.md` | Process documentation | `/workflows/` |
| `battlecard.md` | Competitive positioning | `/sales/` |
| `creative-brief.md` | Design/marketing materials | `/creatives/` |

## Naming Conventions

| Folder | Format | Example |
|--------|--------|---------|
| deliverables | `##-descriptive-name.md` | `14-new-pricing-analysis.md` |
| medical_devices | `##-descriptive-name.md` | `07-supply-chain-analysis.md` |
| workflows | `##-descriptive-name.md` | `06-consumables-workflow.md` |
| sales | `descriptive-name.md` | `battlecard-new-competitor.md` |
| creatives | `##-descriptive-name.md` | `07-trade-show-materials.md` |
