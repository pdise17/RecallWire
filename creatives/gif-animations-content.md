# CANVA ANIMATION REFERENCE

## Recommended Animations by Purpose

| Purpose | Animation | Duration |
|---------|-----------|----------|
| Element appearing | Pop, Rise, Fade | 0.3-0.5s |
| Emphasis | Breathe, Pulse | 0.5-1.0s |
| Text reveal | Typewriter, Fade | 0.5-1.5s |
| Exit/removal | Fade, Tumble | 0.3s |
| Transition | Pan, Slide, Wipe | 0.5s |

## Timing Tips

- **0.3s** — Snappy, energetic
- **0.5s** — Standard, comfortable
- **1.0s** — Deliberate, dramatic
- **1.5s+** — Slow, contemplative

## Stagger Pattern

For sequential elements (like checklist items):
- Start: 0.5s delay
- Each subsequent: +0.3s
- Example: 0.5s, 0.8s, 1.1s, 1.4s, 1.7s
