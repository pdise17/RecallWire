# GIF CONCEPTS

## GIF 1: "Signal vs Noise"

**Purpose:** Show the 98% noise reduction value prop
**Duration:** 4 seconds, infinite loop
**Best for:** LinkedIn, landing pages, email signatures

### Storyboard

| Frame | Duration | Visual | Text |
|-------|----------|--------|------|
| 1 | 0.5s | Empty screen, single alert icon appears | — |
| 2 | 1.5s | Alert icons multiply rapidly, filling screen chaotically (red tint) | "150,000 alerts" |
| 3 | 0.5s | Flash/pulse effect | — |
| 4 | 1.5s | Icons swept away, leaving only 3-4 icons (teal, organized) | "3,000 relevant" |

### Canva Build Notes
- Use "Pop" animation for alert icons appearing
- Use "Tumble" or "Drift" for the sweep effect
- Final state: clean, organized, satisfying
- Add RecallWire logo watermark (bottom right, subtle)

# PRODUCTION NOTES

## Canva Animation Tips
- Use "Animate" tab → Page animations for transitions
- Set timing to 0.5-1.5s per element
- Preview full animation before exporting
- Export as GIF (not MP4) for LinkedIn auto-play

## File Naming
- `recallwire-gif-signal-noise-v1.gif`
- `recallwire-gif-40-to-4-v1.gif`
- etc.

## Optimization
- Keep file size under 5MB for LinkedIn
- 15-20 fps is sufficient
- Loop seamlessly (end state matches start state or hard cut)
