# Hot Recall Email Templates

**Platform:** Canva Email Builder or any ESP (Mailchimp, HubSpot, etc.)
**Width:** 600px max | **Mobile:** Responsive

---

## Quick Brand Reference

| Element | Value |
|---------|-------|
| Primary Blue | #1E3A5F |
| Accent Teal | #00B4A0 |
| Alert Red | #DC2626 |
| Background | #F9FAFB or #FFFFFF |
| Font | System sans-serif (Arial, Helvetica) |

---

## Email Design System

### Header Block
```
┌────────────────────────────────────────┐
│  [LOGO]              [Recall Alert]    │  40px height
│                      badge (red bg)    │
└────────────────────────────────────────┘
```

### Alert Banner (Class I only)
```
┌────────────────────────────────────────┐
│  ⚠️  CLASS I RECALL - IMMEDIATE ACTION │  Red bg (#DC2626)
└────────────────────────────────────────┘   White text
```

### CTA Button Style
- Background: #00B4A0 (teal)
- Text: White, bold
- Padding: 14px 28px
- Border-radius: 6px
- Full width on mobile

# DESIGN TEMPLATES (Canva)

## Template Checklist

- [ ] Header with logo + optional alert badge
- [ ] Red banner (Class I only)
- [ ] Blue section header block
- [ ] Teal CTA button (full-width mobile)
- [ ] Checklist component (checkbox + text)
- [ ] Comparison table (2-column)
- [ ] Stats box (centered, bordered)
- [ ] Recall class indicators (colored left border)

## Mobile Considerations

- Single column layout under 480px
- CTA buttons full width
- Font minimum 14px body, 18px headers
- Tap targets minimum 44px height
