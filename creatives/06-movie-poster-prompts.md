## PRODUCTION NOTES

### Best Practices for Midjourney
- Add `--style raw` for more photorealistic results
- Use `--q 2` for higher quality
- Try `--s 250` for more stylized, poster-like results
- Regenerate 3-4 times and pick best composition

### Post-Processing
- Add RecallWire logo in corner (Canva/Photoshop)
- Adjust text if AI-generated text is garbled
- Color grade to match brand teal (#00B4A0) as accent
- Add film grain overlay for authenticity

### Recommended Output Sizes
- LinkedIn feed: 1200x1200 or 1200x627
- Billboard mockup: 3840x2160
- Print poster: 300dpi at target size
- Instagram story: 1080x1920
