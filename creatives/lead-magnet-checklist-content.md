## Quick Reference Text

```
RECALL CLASSIFICATION & RESPONSE TIMELINES

🔴 CLASS I - IMMEDIATE

"Reasonable probability of serious adverse health consequences or death"

Initial Response:    Same day
Investigation:       24-48 hours
Completion:          ASAP (days, not weeks)

Examples: Implantable devices with failure risk, life-support equipment, contaminated products


🟡 CLASS II - PROMPT

"May cause temporary or medically reversible adverse health consequences"

Initial Response:    1-2 days
Investigation:       1 week
Completion:          2-4 weeks

Examples: Mislabeled products, software bugs with limited patient impact


🟢 CLASS III - ROUTINE

"Not likely to cause adverse health consequences"

Initial Response:    3-5 days
Investigation:       2 weeks
Completion:          As able

Examples: Minor labeling issues, cosmetic defects


KEY COMPLIANCE STANDARDS

Joint Commission EC.02.01.01 EP 11
• Written procedure for monitoring hazard notices/recalls
• Designated responsible person
• Coordination across departments
• Documentation of all actions taken

FDA 21 CFR Part 806
• Document disposition of all recalled devices
• Maintain records for regulatory inspection
```

# CANVA BUILD NOTES

## General Design

- **Pages:** 5 total
- **Size:** Letter (8.5 x 11)
- **Orientation:** Portrait
- **Margins:** 0.5" all sides

## Cover (Page 1)

- Logo centered, 25% width
- Title in Primary Blue (#1E3A5F), 48pt bold
- "Inside this guide" box with light gray background
- Clean, professional, minimal

## Quick Reference (Page 2)

- Class I box: Red left border or light red background
- Class II box: Yellow/amber left border
- Class III box: Green left border
- Standards section: Gray background box

## Checklist Pages (3-4)

- Phase headers: Primary Blue background, white text
- Checkboxes: Large (at least 16px), easy to mark
- Fill-in lines: Dotted or solid, adequate length
- Clear visual hierarchy between phases

## Closure + CTA (Page 5)

- Audit verification: Light teal background box
- CTA section: Teal border, bold headline
- Demo button: Teal background, white text
- Roles section: Simple gray background

## Typography

| Element | Size | Weight |
|---------|------|--------|

| Page headers | 24pt | Bold |
| Phase headers | 14pt | Bold, ALL CAPS |
| Checklist items | 10-11pt | Regular |
| Fill-in labels | 9pt | Regular |
