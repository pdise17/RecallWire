# RecallWire Creative Assets

Modular creative briefs for building marketing materials in Canva.

## Start Here

**`00-launch-runbook.md`** — Master roadmap with phases, priorities, and week-by-week schedule.

## Files

| File | Description | Dependency |
|------|-------------|------------|
| `00-launch-runbook.md` | **START HERE** - Strategic launch roadmap | None |
| `brand-foundation.md` | Colors, fonts, core messaging blocks | Reference only |
| `01-sales-deck.md` | 12-slide pitch deck brief | Standalone |
| `02-one-pagers.md` | Executive, Operations, IT versions | Standalone |
| `03-linkedin-social.md` | Static posts, carousels, content series | Standalone |
| `04-gif-animations.md` | 6 GIF concepts with storyboards | Standalone |
| `05-email-templates.md` | Hot recall campaign emails + nurture sequences | Standalone |
| `06-movie-poster-prompts.md` | AI image gen prompts (Midjourney) - Total Recall theme | Standalone |

## How to Use

Each brief is **self-contained**. Pick any asset and build it without needing the others.

The brand foundation (`00-`) contains shared elements (colors, messaging) but each brief includes its own quick reference section—no cross-file lookup required.

## Suggested Build Order

**Quick wins (1-2 hours each):**
1. Stat cards from `03-linkedin-social.md`
2. "40 to 4" GIF from `04-gif-animations.md`

**High-leverage assets (4-8 hours each):**
3. Sales deck from `01-sales-deck.md`
4. Executive one-pager from `02-one-pagers.md`

**Ongoing content:**
5. "Recall of the Week" series
6. Additional GIFs as needed
