# DESIGN SPECIFICATIONS (All Versions)

## Color Usage

| Element | Color | Hex |
|---------|-------|-----|
| Headlines | Primary Blue | #1E3A5F |
| Stats numbers | Accent Teal | #00B4A0 |
| Body text | Dark Gray | #1F2937 |
| Callout background | Light Teal | #E6FAF8 |
| Callout border | Accent Teal | #00B4A0 |
| Footer background | Light Gray | #F9FAFB |

## Typography

| Element | Size | Weight |
|---------|------|--------|
| Headline | 28-32pt | Bold |
| Subhead | 14-16pt | Regular |
| Section headers | 12-14pt | Bold, ALL CAPS |
| Body text | 10-11pt | Regular |
| Stats numbers | 36-48pt | Bold |
| Stats labels | 8-10pt | Regular |
| Footer CTA | 12pt | Bold |

## Spacing

- **Margins:** 0.5" all sides (minimum)
- **Section gaps:** 0.25-0.375"
- **Column gap:** 0.25"
- **Callout padding:** 12-16px

## Print Checklist

- [ ] Test print at actual size
- [ ] Verify readability in grayscale
- [ ] Check all text is minimum 9pt
- [ ] Confirm logo is high-res (300dpi)
- [ ] Verify QR code scans (if used)
